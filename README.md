# Nukala Sai Kamal — Reference Style Portfolio

This React + Vite project is intentionally styled to match the supplied reference screenshots:
- light gray background
- orange rounded navigation buttons
- large gradient hero name
- yellow layered profile-card effect
- purple social icons
- About page with left-side tabs and a white scrollable content panel
- Projects and Experience pages

## Start

npm install
npm run dev

## Before deployment

1. Put your actual photo into the project and replace the `PhotoCard` placeholder.
2. Put your resume PDF at `public/resume.pdf`.
3. Replace `GITHUB` in `src/App.jsx` with your real GitHub URL.
4. Verify LinkedIn URL.
5. Run `npm run build`.

## Deploy

Push to GitHub, then import the repository into Vercel.
